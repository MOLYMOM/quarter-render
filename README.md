# 4분의 1 — 신들의 카드 전장

갓필드 스타일의 브라우저 카드 배틀입니다. 혼자 하기(AI 3명)와 방 코드 멀티플레이(2~4명)를 지원합니다.

## 구성
- `server.js` — 게임 페이지를 보여 주고, 같은 방 사람들끼리 메시지를 전달하는 서버 (추가 패키지 없음, Node 18 이상)
- `public/index.html` — 게임 전체 (방장 브라우저가 규칙을 계산하고, 서버는 전달만 합니다)
- `render.yaml` — Render 설정

## Render에 배포하기
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다.
2. Render 대시보드 → **New → Web Service** → 그 저장소를 연결합니다.
3. 설정:
   - Runtime: **Node**
   - Build Command: 비워 두거나 `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
   (또는 **New → Blueprint**를 고르면 `render.yaml`을 읽어 자동으로 설정됩니다)
4. 배포가 끝나면 `https://<서비스이름>.onrender.com` 으로 접속해서 플레이합니다.

## 잠들지 않게 하기
무료 플랜은 한동안 접속이 없으면 서버를 재웁니다. 이 게임은 페이지가 열려 있는 동안 **4분마다 `/ping`으로 신호**를 보내므로,
누구 한 명이라도 페이지를 켜 두면 서버가 깨어 있습니다. 모두 닫으면 잠들고, 다음 첫 접속은 깨어나는 데 잠시 걸립니다.
`/ping`은 Render 헬스 체크 주소로도 쓰입니다.

## 멀티플레이
- 방장: 닉네임 입력 → **방 만들기** → 4자리 코드를 친구에게 알려 주기 → **시작**
- 친구: 같은 주소 접속 → 코드 입력 → **참가**
- 빈자리를 AI로 채울지 고를 수 있습니다. 5번째 이후 입장자는 관전합니다.
- 시간제한은 없습니다. 연결이 끊긴 사람의 자리는 15초 뒤 AI가 이어받습니다.
- 방장이 나가면 그 방은 끝납니다(방장 화면이 게임을 진행하기 때문).
- 방 정보는 서버 메모리에만 있어서, 재배포나 재시작하면 진행 중인 방은 사라집니다.

## 로컬에서 실행
```
node server.js        # http://localhost:3000
```
